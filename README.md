## Overview

QRMenu is a modern web application that allows restaurants, cafés, bars and other businesses to provide a fast and convenient digital menu through a QR code.

The project focuses on clean UI, smooth interactions, mobile-first design and high performance without unnecessary frameworks.

---

## Features

* Responsive mobile-first interface
* Smooth category navigation
* Optimized loading speed
* Modern UI/UX
* Service Worker support
* Lightweight architecture
* Vanilla JavaScript
* Easy deployment
* Cross-browser compatibility
